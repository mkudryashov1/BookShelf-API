**BookShelf API**

REST API для управления личной библиотекой книг.

Pet-проект для практики backend-разработки на Go.

**Стек**

- Go
- net/http + chi
- PostgreSQL
- database/sql + pgx
- Docker + Docker Compose
- slog для структурированного логирования

**Запуск**

Запустить приложение вместе с PostgreSQL и миграциями:
docker compose up --build

API будет доступен по адресу:
http://localhost:8080

**Тесты**

Запустить все тесты:
go test ./...

Запустить тесты с проверкой гонок:
go test -race ./...

Integration-тесты используют отдельный PostgreSQL-контейнер.

**API**

| Метод | Endpoint | Описание |
|:------|:---------|:---------|
| `POST` | `/books` | Создать книгу |
| `GET` | `/books` | Получить список книг |
| `GET` | `/books/{id}` | Получить книгу по ID |
| `PUT` | `/books/{id}` | Обновить книгу |
| `DELETE` | `/books/{id}` | Удалить книгу |
| `GET` | `/books/recommend` | Получить рекомендации |
| `POST` | `/books/{id}/mark-out-of-stock` | Отметить книгу как отсутствующую |

**Проверка состояния**

| Метод | Endpoint | Описание |
|:------|:---------|:---------|
| `GET` | `/healthz` | Проверить, что приложение запущено |
| `GET` | `/readyz` | Проверить готовность приложения и соединение с PostgreSQL |

**Пагинация**

Для получения списка книг можно использовать параметры:
GET /books?page=1&limit=10
page — номер страницы, начиная с 1;
limit — количество книг на странице, от 1 до 100.

По умолчанию:
page = 1;
limit = 10.

**Логирование**

Приложение использует структурированное JSON-логирование через slog.
Для HTTP-запросов логируются:

HTTP method;
path;
status;
duration.
